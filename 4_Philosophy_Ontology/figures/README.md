# Figures

## `rolling_wheels.svg` — animated

Four wheels of circumference 2, 3, 5 and 7 rolling along the number line, each with one mark that touches down every *p* steps. **Open it in a browser** — GitHub's markdown view will show it as a still.

Generated by [`gen_rolling_wheels.py`](gen_rolling_wheels.py), standard library only.

**The phases are real.** At position *x*, wheel *p* has rolled *x* units from zero, so its rotation is 360·*x*/*p* degrees. All four marks touch down together at 0 and do not coincide again until 210.

**The window is 100–130 on purpose.** Seven positions there are open to all four wheels — 101, 103, 107, 109, 113, 121, 127 — and six are prime. The seventh is **121 = 11²**, open but composite, because it is exactly where the first wheel you did not carry begins striking things the smaller ones miss. Below 121 four wheels are *exact*; from 121 they are not.

That is [The Movie](../The_Movie.md) §2 — a wheel does nothing new below its own square — seen from the other side.

## `fig2_guth_maynard_cusp.svg`

**Where θ = 17/30 actually comes from.** Two rational curves meet at σ = 7/10:

| | | |
|---|---|---|
| Ingham (1940) | $A(\sigma) = 3/(2-\sigma)$ | binding on $[1/2, 7/10)$ |
| Guth–Maynard (2024) | $A(\sigma) = 15/(5\sigma+3)$ | binding on $[7/10, 19/25)$ |

Each curve is drawn solid where it binds and dashed where it doesn't, so the cusp is visibly a *crossover* rather than a kink in one function.

**Everything plotted was verified as exact rational arithmetic before drawing:**

$$A_{\mathrm{Ing}}(7/10) = \frac{3}{13/10} = \frac{30}{13}, \qquad A_{\mathrm{GM}}(7/10) = \frac{15}{13/2} = \frac{30}{13}$$

$$\theta = 1 - \frac{1}{\|A\|_\infty} = 1 - \frac{13}{30} = \frac{17}{30}, \qquad \frac{d\theta}{d\|A\|} = \frac{1}{\|A\|_\infty^2} = \frac{169}{900}$$

All four hold exactly, not numerically. The script asserts them at generation time, so the figure cannot be produced from wrong numbers.

**Why this is the paper's most communicative picture.** The whole five-dimensional apparatus exists to locate one point. The height of that point *is* the prime-gap exponent, and the sensitivity coefficient says that lowering it by δ buys you about 0.19 δ of θ. That is the entire attack surface, in one image.

## ⚠️ A discrepancy found while drawing (2026-09-20)

Not in the main result — in the historical before/after remark.

[`GuthMaynard_BindingConstraints.md`](../../Archive/X5D%20EXPDB%20Framework/examples/GuthMaynard/) states that before Guth–Maynard, *"the analogous cusp was at σ ≈ 5/7 ≈ 0.714, where Ingham met Huxley at ‖A‖∞ = 12/5."*

**Those two values are inconsistent with each other**, on the same document's own Ingham curve:

$$A_{\mathrm{Ing}}(5/7) = \frac{3}{2 - 5/7} = \frac{3}{9/7} = \frac{7}{3} \approx 2.333 \;\neq\; \frac{12}{5} = 2.4$$

If the peak height was $12/5$, then Ingham's curve forces $\sigma$ exactly: $3/(2-\sigma) = 12/5 \Rightarrow \sigma = 3/4$.

And the Huxley form coded in the upstream `gen_figures.py` — `A_huxley(s) = 12*(1-s)/5` — **never crosses Ingham anywhere in $(1/2, 1)$**; solving the two gives $\sigma = (3 \pm \sqrt6)/2$, i.e. $0.275$ or $2.72$, both outside the range. That expression equals $12/5$ only at $\sigma = 0$.

The textbook Ingham–Huxley crossover uses $A_{\mathrm{Hux}}(\sigma) = 3/(3\sigma-1)$, which meets $3/(2-\sigma)$ at exactly $\sigma = 3/4$ with height $12/5$ — consistent with the quoted peak and with the standard literature. **That is likely the intended statement**, but it is offered as a reading, not asserted as the author's meaning.

**Scope:** peripheral. The main chain — cusp at 7/10, peak 30/13, θ = 17/30, sensitivity 169/900 — is unaffected and verifies exactly. What is wrong is the sentence describing the *previous* state of the art, and the σ value in the comparison table. Neither figure here depends on it, and neither draws the Huxley curve.

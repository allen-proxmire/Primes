# 3 — Twin Bertrand

**One conjecture and two geometries that reach it.** Every $(x,2x]$ with $x\ge11$ contains a twin prime: $\pi_2(2x)-\pi_2(x)\ge1$. Verified to $10^{10}$ — 27,412,679 twins, no exceptions.

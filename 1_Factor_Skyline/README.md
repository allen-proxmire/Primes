# 1 — The Factor Skyline

**The lens.** Stand every integer up as a column, with its width set by its smallest prime factor. Primes escape to a diagonal; every composite falls onto one of a fan of rays. Facts that look unrelated on the flat number line become one picture here.

This folder is the **foundation** — the coordinate system and the theory built on it. It is the most technical material in the collection and the least necessary to read first.

**Start with:** [FSPapers_01](FSPapers_01_architectural_foundation.md) for the architecture. If you only want one idea from this folder, it is in [`FSPapers_02.1` §13](FSPapers_02.1_correlations_and_randomness.md): the primes are generated by a rule simple enough to write on a napkin, yet the output passes every test for randomness. That gap is the whole subject.

**Also here:** [FS_primorial_epochs](FS_primorial_epochs.md), promoted out of the archive in September because §2.2 keeps getting rediscovered — it is the reason the pattern can never be caught repeating. [DERIVATION_MODULES](DERIVATION_MODULES.md) indexes 18 further derivation notes that live in an untracked upstream repo and which an ordinary search will miss.

**Reproducibility:** [`repro/`](repro/) covers the headline entropy numbers only. Worth knowing that the upstream reproducibility tree turned out to be placeholder stubs — those numbers had never actually been re-derived until September 2026.
